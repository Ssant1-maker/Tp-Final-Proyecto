# AGENTS.md

## Project
Aplicación web en React y TypeScript para control de gastos personales y presupuestos mensuales.

## Commands
- `npm install`: Instalar dependencias del proyecto
- `npm run dev`: Levantar el entorno de desarrollo local
- `npm run build`: Compilar el proyecto para producción
- `npm run test`: Ejecutar los tests unitarios

## Code style
- Usar TypeScript estricto en todos los archivos.
- Prohibido usar `any` (definir interfaces o tipos explícitos).
- Nombres claros y descriptivos en inglés para código, textos visibles en español.
- Componentes en `PascalCase`, funciones y variables en `camelCase`.
- Mantener los componentes pequeños y con una única responsabilidad.
- Priorizar componentes funcionales y hooks personalizados para la lógica.

## Agent behavior
### Qué puede hacer el agente
- Crear y modificar componentes de interfaz siguiendo el estilo definido.
- Escribir y actualizar tests unitarios para nuevas funcionalidades.
- Refactorizar código duplicado para mejorar la legibilidad.
- Corregir errores de tipado o advertencias del linter.

### Qué NO debe hacer sin permiso
- Instalar nuevas librerías o paquetes externos en `package.json`.
- Modificar archivos de configuración global (`tsconfig.json`, `vite.config.ts`, `.env`).
- Eliminar archivos o carpetas existentes del proyecto.
- Hacer commits o push directamente al repositorio remoto.
